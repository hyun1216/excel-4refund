# 엑셀 버전 개발 진척도 요약

> 기준일: 2026-10-27  
> 기준 문서: `Brity_RPA_매크로_현행구현_갭분석_2026-10-15.md`  
> 범위: 세무프로그램 자동 다운로드, Google Drive, 이메일을 제외한 로컬 Excel 처리  
> 주의: 현재 전체 실행 중이므로 코드 수정이나 테스트 재실행 없이 현재 코드와 최근 완료된 테스트 결과만 반영했다.

## 1. 전체 구현률

| 평가 범위 | 구현률 | 판단 |
|---|---:|---|
| 입력 접수 → 기초정보·연도별 급여대장 → 급상여현황 → 수정신고 입력자료 | **약 86%** | 핵심 Excel 흐름 구현 완료, 직업분류 통합과 일부 오류 수정 필요 |
| 갭분석의 전체 업무 끝단까지 포함 | **약 68%** | 수정 원천징수 최종 실행, 추가서류, 제출자료, 최종 ZIP이 미완성 또는 현재 실행기에 미연결 |
| 자동화 테스트 | **95.5%** | 최근 결과 44건 중 42건 통과, 2건 실패 |

| 갭분석 업무 구간 | 구현률 | 구현된 내용 | 남았거나 수정할 내용 |
|---|---:|---|---|
| 실행 준비·입력 접수 | **90%** | 공용 input 분류, 업체 폴더 생성, 파일 이동, 접수 보고서, 로그, 기존 업체 폴더 재개 | 단계·연도별 체크포인트, 사용자용 체크리스트 |
| 원천징수 PDF 분할·추출 | **85%** | 개인본·통합본 판별, 개인별 분할, 원본 보존, 기초정보용 값 추출 | `_write_template_inputs` 미정의 오류, 신규 PDF 서식 회귀검증 |
| 급여대장 one-row 정규화 | **95%** | 일반·코드형 Excel, 반복 헤더, 지급·공제 분리, 12개월 시트, 합계 검증 | SCK 이외 변형 업체 추가 검증 |

| 지급항목 분류 | **90%** | 직접 매핑, 제외 규칙, 키워드, 미분류 처리, 매칭표 로딩 | 명시적인 사람 승인 이력과 미분류 승인 게이트 |
| 급상여현황 생성 | **85%** | 전체인원, 대상자(작업), 대상자, 비대상자, 검토 보고서 | 현재 SCK 전체 결과의 인원·금액 대사 |
| 직업분류 코드 매핑 | **75%** | 독립 매핑기, 지정 매핑 14건, 소분류 후 중분류 fallback, 결과 검증·백업 | 독립 매핑기와 기초정보 적재기의 규칙·파일 선택·코드 자리수 통합 |
| 수정신고 입력자료 | **80%** | 수정 급상여현황, 수정 원천징수 Tool, 월별 급여대장 생성 | 실제 Excel·매크로 호환 검증, 승인값 적용 전후 대사 |

| 추가서류·기관 제출자료 | **20%** | 출력 폴더와 일부 골격 존재 | 국세청·공단 승인 템플릿, 대상자명단, 청구서, 공문, 제출 임금대장 구현 |
| 최종 검증·ZIP | **40%** | JSON 보고서, 일부 manifest·패키징 모듈 존재 | 모든 단계 결과 대사 후 최종 제출 ZIP까지 현재 전체 실행기에 연결 |
| 장애 복구·이어하기 | **60%** | 입력 접수 생략 재개, 실패 시 임시 결과 제거 | 완료 단계·연도·시트 단위 재개 |

## 3. 구현 완료로 볼 수 있는 항목

- 공용 input의 파일 분류와 업체 폴더 이동
- 직업분류 매핑 결과 파일의 업체 폴더 이동
- 원천징수영수증 분할과 개인별 보관
- 일반 및 코드형 Excel 급여대장의 직원 1명당 1행 변환
- SCK 급여대장의 반복 헤더와 구간별 수당명 처리
- 동일 코드가 월별로 다른 수당명인 경우 별도 열 유지
- 지급합계·공제합계·차인지급액 검증
- 연도별 01월~12월 급여대장 생성
- 단일 기초정보 파일 생성 및 지급·공제 항목 반영
- 지급항목 매칭표 기반 분류
- 급상여현황의 전체인원·대상자·비대상자 생성
- 수정 급상여현황, 원천징수 Tool, 월별 급여대장 생성
- 실행 로그와 단계별 JSON 결과 보고서

## 5. 아직 구현해야 하는 항목

1. 수정 원천징수영수증 생성부터 재추출·수정 전후 값 비교까지의 완전한 자동 연결
2. 수정 결과를 반영한 기초정보 최종 갱신

4. 환급대상자만 포함한 기관 제출 임금대장
5. 수정 전·후 원천징수영수증의 기관별 폴더 자동 분류
6. 전체 산출물 수량·인원·금액 대사
7. 최종 제출 ZIP과 해시 manifest의 현재 전체 실행기 연결
8. 단계·연도별 이어하기와 재처리 이력
